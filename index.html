Home Package Tracker

Home Package Tracker is a personal, single-user tool that scans the owner's own Gmail inbox for shipping-notification emails (USPS, UPS, FedEx, DHL, Amazon), extracts tracking numbers, and displays upcoming delivery dates on a private home dashboard. The carrier status shown on that dashboard is scraped from the carriers' own public tracking pages.

How the app uses Gmail data

The app requests read-only access (gmail.readonly — and message modification is not used) to one mailbox only: the developer's own account, samman9000@gmail.com. There are no other users; the app is not distributed or marketed.

What data is accessed

  • Emails matching shipping-notification search queries (subject, sender, body text).
  • Only the portions of those emails used to detect tracking numbers and delivery dates.

What happens to that data

  • Extracted tracking numbers, statuses, and dates are stored only on the owner's own computer, in a local JSON file.
  • Nothing is sent to, shared with, sold to, or stored by any third party.
  • Email contents are never logged or displayed beyond the dashboard view.
  • No data is used for advertising or model training.
