Home Package Tracker — Privacy Policy

Last updated: 2026-11-20

Home Package Tracker is a private, single-user application. This policy describes how it handles Gmail data.

Data accessed from Google

Using OAuth 2.0, the app receives access to one Gmail mailbox (samman9000@gmail.com) with read-only scopes. It reads only emails that match shipping-notification search queries and processes them to extract tracking numbers, shipping statuses, and estimated delivery dates.

Data storage

All extracted data is stored locally, on the owner's own computer, in a local JSON database. No Google user data is stored on, transmitted to, or made available to any third-party server. There is no external backend.

Data sharing & sale

Google user data is never shared with, sold to, or transferred to third parties (other than Google's own APIs as necessary), and is never used for advertising, marketing, or AI/model training.

Data retention & deletion

The user may delete the local database at any time, and may revoke the app's access at myaccount.google.com/permissions. Outdated records are periodically removed by the app itself.
